# Script Index — Active RoBMA v4 Selected-Rigor Project

Authoritative inventory of every active numbered script. All
`scripts/*.R` and `simulation/scripts/*.R` files are **define-only on
source** (sourcing installs functions/constants + a load sentinel and
guarded `source()` chains; no read/fit/write/heavy-attach). Only
`fit_robma_models()` (20) and `batch_fit()` (40) — and the run driver
that calls them — execute MCMC.

Vocabulary is v4 end to end: `scheme, stratum, corpus_id,
source_article, source_key, source_year, outcome_slug, dataset_id,
analysis_id, analysis_variant`. Legacy `topic/headline/archetype` survive
only in deprecated back-compat shims, old-schema rejection logic, and
lineage comments (see `docs/project_cleanup_ledger.md`).

- **Heavy MCMC (never run during another fit):** `scripts/20_robma_fit.R::fit_robma_models()`, `scripts/40_batch_fit.R::batch_fit()`, `simulation/scripts/40_sim_run.R::sim_fit_library()`.
- **Writes outputs but no MCMC:** `60_estimand_tables`, `30/50/70` figures, `30_sim_export`, `40_sim_run`, `45_study_geometry`, `50_sim_fit_monitor` (progress only), `55_sim_cell_diagnostics`, `60_empirical_resampling`, `65_synthetic_resampling`, `70_empirical_synthetic_agreement`, `75_analysis_visuals` (renamed from `75_composition_visuals` in 2026-05).
- **Read-only / pure:** `00_utils`, `10_load_data`, `00_sim_utils`, `10_sim_design`, `20_sim_generate`, acceptance functions in `40_batch_fit`.
- **Safe while the full36 fit runs:** every read-only/figure/monitor script (`50/55_sim_*`, `60/65/70/75` resampling-composition layer, `45_study_geometry`) — none touch `output_sim_v30` except read-only.
